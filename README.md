# Python Password Generator & Hasher 🔐

A simple and effective cybersecurity tool written in Python. This script automatically generates a strong, 12-character random password and calculates its MD5 and SHA-256 hashes.

## Features
- Generates a secure random password using letters, numbers, and symbols.
- Converts the password into an MD5 hash.
- Converts the password into a highly secure SHA-256 hash.
- Great for understanding the basics of cryptography and hashing in ethical hacking.

## Requirements
- Python 3 installed on your system.

## How to Use
1. Clone this repository to your terminal:
   `git clone https://github.com/pranjal211025/Python-Password-Hasher.git`

2. Open the folder:
   `cd Python-Password-Hasher`

3. Run the Python script:
   `python3 hasher.py`
